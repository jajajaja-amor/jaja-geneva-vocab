# 日内瓦突击计划复刻版

根据用户提供的 https://jaja-geneva-vocab.vercel.app/ 公开页面重建。保留湖蓝色界面、四个主导航和 569 条公开词汇，应用逻辑重新实现，无需安装依赖或提供模型 API Key。

## 运行

在本目录执行 `node server.mjs`，浏览器访问 http://127.0.0.1:4173 。也可以直接打开 `dist/index.html`（建议使用 HTTP，以获得稳定的本地存储与浏览器功能支持）。

## 功能

- 中英文、词根搜索与学习状态筛选；单词详情、音标、词根、双语例句。
- 每日最多 50 个不同词条，优先安排忘记和未学词；记住、忘记、跳过、重练及结算。
- 使用设备浏览器的英语语音朗读，语音可用性取决于浏览器及系统语音包。
- 最近七天学习记录曲线和表格。
- TXT 拖拽、上传、粘贴、预览确认、去重；JSON 学习备份导出及恢复。
- 数据使用当前浏览器 localStorage 独立保存，不与原站或其他设备自动同步。

## 与原站的区别

这是可维护的功能复刻，不是原始 Next.js 工程。路由使用 hash，可静态部署。原站 TXT 服务端解析替换为本机确定性解析；不会自动生成缺失释义。导入新词不打断当天队列，下一天参与抽取；词库不足 50 时不重复凑数。曲线展示真实标记次数，不推算遗忘概率。原站学习记录不会自动迁移。

## 文件和检查

`dist/app.js` 为交互逻辑，`dist/style.css` 为样式，`dist/vocab.js` 为词库。`reference/` 为公开页面参考，不纳入部署仓库。运行 `node check.mjs` 检查队列、状态保存、导入去重、搜索、页面渲染与跨日更新；运行 `node --check dist/app.js` 检查语法。`prepare.mjs` 可以从保存的公开词库脚本重新生成词库。
